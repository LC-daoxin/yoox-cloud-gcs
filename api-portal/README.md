# 上云 API 在线文档门户

一个零构建依赖的纯静态文档站，用于在线呈现上云 API 开发者文档。
布局采用文档站常见的三栏结构（顶部导航 + 左侧目录树 + 右侧内容与页内锚点），
交互（页面切换、页内目录、搜索过滤、代码复制、移动端抽屉）由原生 JS 实现。

## 内容章节

基础介绍

- 产品介绍：上云 API 概述、核心理念、能力范围与开发边界
- 产品架构：端边云分层、通信链路、典型数据流与部署要求
- 产品支持：设备类别、标识规则、适配流程与能力验收矩阵
- 协议能力矩阵：区分基础能力、可选能力与扩展能力

接入

- 设备上云接入：接入架构、上云交互时序、应用凭据、MQTT Topic 体系、消息信封、上线数据流

功能集合

- 态势感知：设备拓扑、OSD 遥测、上下线推送
- 直播功能：直播能力、开始/停止/清晰度/镜头、媒体链路（RTSP→WHEP）
- 地图元素：元素模型、workspace 同步、HTTP + WebSocket 接口
- 媒体管理：上传临时凭证、上传结果上报、媒体归档与短时 URL
- 航线管理：任务类型（立即/定时/条件）、下发与执行、进度上报、航线与任务 API
- HMS 健康管理：健康告警上报、文案 Key 拼接、全量告警语义
- 指令飞行：控制权、DRC 流程、flyto/一键起飞、云台与负载控制

API 介绍

- MQTT Topic 与物模型：Topic 定义、state/OSD 频率语义、物模型方法清单、ACL
- HTTPS 接口清单：鉴权/设备/固件/直播/控制/航线/地图/媒体日志运维
- WebSocket 接口：连接认证、biz_code 业务码
- 航线文件格式标准（WPML）：KMZ/WPML 文件结构与核心元素
- WPML 元素字段参考：任务配置、设备与负载、坐标与高度、航点、动作组及专项任务参数
- 错误码与安全基线：统一错误处理约定、部署安全基线

> 内容采用厂商中立的参考协议与资源模型，不绑定具体产品、代码仓库或部署实现。
> 接入方应结合自身 OpenAPI、设备能力声明和联合测试形成最终接口契约。

## 目录结构

```
api-portal/
├── index.html          # 单页文档站（结构 + 全部内容）
├── assets/
│   ├── styles.css      # 文档站样式
│   └── app.js          # 导航、目录、搜索、复制等交互
├── Dockerfile          # nginx 静态服务镜像
├── nginx.conf          # 静态站点 nginx 配置
└── README.md
```

## 本地预览

任意静态服务器即可，例如：

```bash
cd api-portal
python3 -m http.server 8081
# 打开 http://127.0.0.1:8081
```

## 容器部署

已集成到根目录 `compose.yml` 的 `api-portal` 服务，随主栈一起启动：

```bash
docker compose --env-file .env up -d --build api-portal
# 访问 http://<YOOX_PUBLIC_HOST>:<YOOX_API_PORTAL_PORT>
```

端口由 `.env` 中的 `YOOX_API_PORTAL_PORT`（默认 `8081`）控制。
